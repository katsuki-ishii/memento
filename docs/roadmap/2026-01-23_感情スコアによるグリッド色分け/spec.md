# 感情スコアによるグリッド色分け機能

## 概要

GitHubのContributions Graphのように、週ごとのイベントの感情スコア（mood）に応じてグリッドセルの色の濃淡を変える機能を実装する。

## 目的

- 過去の週に記録したイベントの感情スコアを視覚的に把握できるようにする
- 人生の時間の使い方と感情の傾向を可視化する

## 仕様

### 色の設計

**基本方針**: GitHub風の濃淡アプローチ（単色の濃淡で表現）

**使用色**: 緑系（Tailwind CSSのgreen系）

**色の段階（感情スコアに応じた濃淡）**:

- `very-good`: `bg-green-600`（最も濃い）
- `good`: `bg-green-400`（やや濃い）
- `neutral`: `bg-green-300`（中間）
- `bad`: `bg-green-200`（やや薄い）
- `very-bad`: `bg-green-100`（最も薄い）

**イベントなしの場合**:

- 過去の週: `bg-gray-200`（薄いグレー）
- 未来の週: `bg-gray-100`（さらに薄いグレー、現状維持）

**現在週の扱い**:

- アクセントカラー（`bg-accent`）を優先
- イベントの有無に関わらず、現在週は常にアクセントカラーで表示

### 凡例

- すべての色を説明する必要はない
- 「緑は記録したイベントの感情スコアを表します」程度の説明のみ
- 詳細な色の段階は説明しない

### イベントデータ取得

**方式**: 全イベント一括取得（選択肢A）

**実装**:

- APIエンドポイント: `GET /events`（weekIdパラメータなし）で全イベントを取得
- または既存エンドポイントを拡張: `GET /events`で全イベント、`GET /events?weekId=...`で特定週

**データ取得タイミング**:

- ホームページ（Dashboard）のマウント時に全イベントを取得
- 取得したデータはグリッドストア（`eventsByWeek`）に保存
- イベント作成/更新/削除時はストアを更新（再取得不要）

**パフォーマンス考慮**:

- イベント数は多くても数百件程度と想定
- レスポンスサイズは数KB〜数十KB程度
- 初回ロード時に全イベントを取得するが、その後はストアにキャッシュ

### 実装箇所

1. **`GridCanvas.vue`の`weekClass`関数を修正**
   - その週のイベントを`eventsByWeek`から取得
   - イベントがあれば感情スコアに応じた色を返す
   - イベントがなければ現在の実装通り（過去は`bg-gray-200`、未来は`bg-gray-100`）

2. **`Dashboard.vue`で全イベント取得**
   - マウント時に`listEvents()`をweekIdなしで呼び出し
   - 取得したイベントをグリッドストアに保存

3. **凡例の更新**
   - 感情スコアに応じた色の説明を追加（簡潔に）

### 非対応事項

- 複数イベント: 1週に複数のイベントは想定しない
- ダークモード: 現時点では考慮しない
- 色覚多様性: 現時点では考慮しない

## 技術的詳細

### 感情スコアの値

```javascript
const moodValues = [
  'very-bad', // 😢
  'bad', // 😞
  'neutral', // 😐
  'good', // 😊
  'very-good', // 😄
];
```

### 色のマッピング

```javascript
const moodColorMap = {
  'very-good': 'bg-green-600',
  good: 'bg-green-400',
  neutral: 'bg-green-300',
  bad: 'bg-green-200',
  'very-bad': 'bg-green-100',
};
```

### イベントデータ構造

```javascript
{
  id: 'EVENT#1714123456789',
  weekId: '1990-W00',
  title: 'イベントタイトル',
  mood: 'good',  // 感情スコア
  note: 'メモ',
  createdAt: 1714123456789
}
```

## 実装順序

1. APIエンドポイントの拡張（`GET /events`で全イベント取得対応）
2. フロントエンドで全イベント取得処理を追加
3. `GridCanvas.vue`の`weekClass`関数を修正
4. 凡例の更新
