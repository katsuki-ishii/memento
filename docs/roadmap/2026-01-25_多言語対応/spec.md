# 多言語対応 仕様

## 概要

- UI文言を日本語/英語で切り替え可能にする。
- 言語切替は設定画面のみで行う。
- 初回はブラウザ言語を自動判定し、以後はユーザー設定を優先する。

## 目的

- UIの理解性を高め、利用開始のハードルを下げる。
- 将来的な言語追加に備えて文言の外部化基盤を作る。

## スコープ

### 対象

- UI文言のみを翻訳対象とする。
- 設定画面に言語選択UIを追加する。
- `ja` / `en` の2言語のみを対象とする。

### 非対象

- ユーザー入力データの翻訳。
- 自動判定に追従し続ける「自動」モードの提供。
- 地域差分（`en-US` など）の細分化。

## 仕様

### 言語コード

- 設定値は `locale` を採用する。
- 値は `ja` / `en` のいずれか。
- `locale` は「言語+地域」の一般的な識別子であり、将来拡張に合わせやすい。

### 初期言語の決定

- 既に保存済みの `locale` がある場合はそれを優先。
- 未設定（`locale` が未存在 or `null`）の場合はブラウザ言語（`navigator.language` / `navigator.languages`）を参照。
- 対応言語に一致しない場合は `en` にフォールバック。
- 初回判定結果は保存し、次回以降は保存値を使用する。

### 設定画面UI

- 言語選択（`日本語` / `English`）を追加する。
- 変更は即時反映（リロード不要）。
- 保存時に `/me/settings` へ `locale` を含めて更新する。

### 表示と言語反映

- UI文言は辞書から取得する。
- `html` タグの `lang` を `locale` に合わせて更新する。

## 技術方針

- Vue i18n を導入し、辞書ベースで文言を管理する。
- 翻訳キーは「画面や機能」を起点にしつつ、汎用要素は `common` に集約する。
  - 画面固有の文言は `login.*` のように画面名でグルーピングする。
  - 汎用的なボタンやラベルは `common.actions.*` / `common.labels.*` にまとめる。
  - バリデーションエラーは `errors.*` に集約する。
  - トースト文言は `toast.*` に集約する。
- 既存文言の外部化は段階的に進める。

## 影響範囲

- フロントエンド: 主要画面の文言置き換え、設定画面のUI追加。
- バックエンド: `/me/settings` の `locale` 保存対応。
- データ: `UserSettings` に `locale` を追加。

## 受け入れ条件

- 設定画面で言語を切り替えるとUI文言が即時に切り替わる。
- ブラウザ言語が `en` の場合、初回表示が英語になる。
- 未対応言語の場合は英語にフォールバックする。
- 設定保存後、再読み込みしても選択した言語が維持される。
