# Issues（問題・改善記録）

## 目的

- 開発中に発見した問題点、微修正、改善点を記録・管理する。
- plan.md（WBS）とは別に、発生ベースの課題をトラッキングする。
- 解決済みの課題も履歴として残し、同様の問題発生時の参考とする。

## 記録形式

- [x] 解決済み
- [ ] 未解決

---

- [x] トップページの哲学が伝わらない
  - [x] 問題: 初期コピー「あなたの時間を、週で見える化する」ではMementoの哲学が伝わらない
  - [x] 対応: メインコピーを「時間はもっとも貴重なリソースです。しかし、人は寿命が長すぎてその尊さを認識できていません。」に変更
  - [x] 対応: サブコピーを「人生を週単位で可視化し、すでに使った時間と、これからの時間を見つめ直しましょう。」に変更
  - [x] 対応: 不要なグリッドサンプル、ダッシュボードボタンを削除
  - [x] 対応: 左寄せレイアウト、フェードインアニメーションでデザイン刷新
- [x] ホームの進捗サマリー不要
  - [x] 問題: 進捗サマリーパネルが不要
  - [x] 対応: SummaryPanelを削除、グリッドを水平中央配置

- [x] グリッドセル間の謎の空白問題
  - [x] 症状: 10週ごとにセルが消えて空白に見える
  - [x] 原因: `hasEvent: w % 10 === 0` でデモ用イベントフラグが設定されていた
  - [x] 原因: `bg-primary/70`（CSS変数 + 透明度修飾子）が正しく機能せず、セルが透明/背景色と同化
  - [x] 対応: デモ用イベントフラグを無効化（`hasEvent: false`）
  - [x] 学び: TailwindのCSS変数と透明度修飾子（`/70`等）の組み合わせは注意が必要
- [x] グリッド内スクロール問題
  - [x] 問題: `max-h-[520px] overflow-y-auto` で全体を俯瞰できない
  - [x] 対応: 高さ制限を削除、ページ全体でスクロールする形に変更
- [x] グリッドの週区切り
  - [x] 問題: 10週ごとに間隔が空いているように見える（上記の空白問題と関連）
  - [x] 対応: 4週ごとに明示的にグループ化（`chunkWeeks`関数）、グループ間に間隔を設定
- [x] グリッドの色分けロジックがMementoの本質と合っていない

  - [x] 対応: 色分けロジックを過去（使った時間）/現在週/未来（残りの時間）に変更
  - [x] 対応: 過去は `bg-gray-300`、現在週は `bg-accent`、未来は `bg-gray-100` に変更
  - [x] 対応: 凡例も「未記録/イベントあり/今週」から「過去（使った時間）/今週/未来（残りの時間）」に変更
