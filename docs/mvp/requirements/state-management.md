# 状態管理 (Pinia) 要件

- 目的: 認証状態・ユーザー設定・ライフグリッド/イベントデータを一元管理し、ルーターガードや各画面から再利用可能にする。
- 技術: Pinia (setup store)。型は JSDoc で最小限注釈。
- ストア構成（暫定）
  - `useAuthStore`: アクセストークン/リフレッシュトークン、ユーザーID、トークン更新メソッド、`isAuthenticated`/`isExpired` フラグ。
  - `useProfileStore`: プロフィール・初期設定済みフラグ・寿命設定・週開始曜日。設定更新の API 呼び出しを内包。
  - `useGridStore`: ライフグリッドの週データ、選択週、イベント一覧のキャッシュ、フェッチ状態。
  - `useUiStore`: トースト/モーダル/ローディングフラグ/テーマ。
- 永続化: `useAuthStore` のトークンのみ `secure storage` (localStorage) へ暗号化せず保持しない方針。その他ストアはメモリのみ。ブラウザリロード時は再フェッチ。
- エラーハンドリング: API 例外を正規化したエラー型で返し、UI ストア経由で表示。再ログイン要求時は `useAuthStore.logout()` を呼びルーターへ通知。
- テスト: 各ストアは Vitest + jsdom でユニットテストを用意（状態遷移、ガード条件、永続化動作）。
