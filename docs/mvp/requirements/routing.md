# ルーティング要件

- 目的: 認証状態と初期設定完了状態に応じた遷移制御を行い、URL 直打ちでも一貫した UX を保証する。
- 技術: Vue Router 4 (history モード)。ルート定義は `src/router/routes.js` に集約。
- ガード
  - グローバル beforeEach でトークン検証/リフレッシュ結果を考慮。
  - `meta.requiresAuth`: 未認証なら `/auth/start` へリダイレクト。
  - `meta.requiresSetup`: 認証済みかつ未設定なら `/setup` へ。
  - 認証済みユーザーが `/auth/*` へアクセスした場合、設定有無により `/dashboard`（ホーム）または `/setup` へ遷移。
- 主要ルート
  - `/` ホーム (公開)
  - `/auth/start` 認証開始 (公開)
  - `/auth/callback` 認証コールバック (公開、トークン処理後にリダイレクト)
  - `/setup` 初期設定 (要認証、初期設定未完ユーザーのみ)
  - `/dashboard` ホーム (要認証、初期設定済み)
  - `/:pathMatch(.*)*` 404
- エラーハンドリング: ガード中の例外は `/error` へ遷移し、状態をログ出力（コンソール + Sentry 導入想定）
- ローディング: ガード中はページトップにプログレスバー or フルスクリーンスピナーを表示（Pinia の `app/ui` ストアで制御）。
