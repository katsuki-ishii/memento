# ホーム（非認証）要件

- 目的: 初めて訪れたユーザーにMementoの哲学を伝え、サインアップ/ログインへ誘導する。
- UI:
  - ロゴ: "Memento"（小さくサブタイトル的に配置）
  - メインコピー: 「時間はもっとも貴重なリソースです。しかし、人は寿命が長すぎてその尊さを認識できていません。」
  - サブコピー: 「人生を週単位で可視化し、すでに使った時間と、これからの時間を見つめ直しましょう。」
  - CTAボタン: 「サインアップ / ログイン」（1つのみ）
- 操作: CTAで認証フローへ遷移（Cognito Hosted UI/PKCE）。
- 認証: 不要（誰でもアクセス可）。認証済みの場合は初期設定またはホームへリダイレクト。
- ナビ: サイドメニューボタンは非表示。フッター等に簡易リンクのみ。
- スタイル: Notionライク白黒、広めの余白、中央揃え、最小限のアクセントカラー。グリッドサンプル等の装飾は不要。
