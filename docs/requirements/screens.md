# 画面仕様 (Screens)

## ホーム（非認証）

- 目的: 初めての訪問者にコンセプトを伝え、サインアップ/ログインへ誘導する。
- 主なUI: ロゴ＋タイトル "Memento"、サブメッセージ（例: "あなたの時間を、週で見える化する"）、CTAボタン2つ「サインアップ」「ログイン」。
- 操作: CTAで認証フロー（Cognito Hosted UI/PKCE）へ遷移。認証済みで来た場合は初期設定またはダッシュボードへリダイレクト。
- 認証要否: 不要。

## 認証画面

- 目的: サインアップ/ログイン/ログアウトを行う。
- 主なUI: メール/パスワード入力、送信ボタン、エラーメッセージ、サインアップ⇄ログイン切替リンク。
- 操作: フォーム送信で Cognito Hosted UI/PKCE にリダイレクト。認証成功後、ユーザー設定が未完なら初期設定へ、完了していればダッシュボードへ遷移。
- 認証要否: 非認証でもアクセス可。認証済みは初期設定/ダッシュボードへ即リダイレクト。

## 初期設定画面

- 目的: 初回ログイン後に必須のユーザー設定を入力・保存し、ダッシュボード利用を可能にする。
- 主なUI: username, birthYear, lifespan(年), weekStart(初期:月曜), theme のフォームと保存ボタン。
- 操作: 保存で設定を確定し、成功後ダッシュボードへ遷移。キャンセルはログアウトまたはホームへのリンクのみ。
- 認証要否: 必須。設定済みユーザーはここをスキップしてダッシュボードへ。

## ダッシュボード（ライフグリッド）

- 目的: ライフグリッドを俯瞰し、イベント有無と現在週を確認する。
- 主なUI: 寿命×52週グリッド、現在週ハイライト、イベント有りセルの色分け、簡易サマリー（記録週数、残り寿命の週/日/%）。
- 操作: セルクリックでイベント追加/編集ダイアログを開く。週のフィルタ/ジャンプ（年・週入力）を提供。
- 認証要否: 必須。初期設定未完の場合は初期設定へリダイレクト。
- ナビゲーション: サイドメニューボタンで開閉し、メニューに「ダッシュボード」「設定」「ログアウト」を配置。

## イベント編集ダイアログ

- 目的: 週に紐づくイベントを登録/編集/削除する。
- 主なUI: タイトル、メモ、感情スコア（選択）、保存/削除ボタン。対象週の表示。
- 操作: 保存でイベント作成/更新、削除で該当イベントを削除。閉じる操作でキャンセル。
- 認証要否: 必須（ダッシュボードからのみ起動）。

## 設定画面

- 目的: ユーザー設定を更新し、グリッド表示に反映させる。初期設定完了後の再編集用途。
- 主なUI: ユーザー名、生年、寿命年数、週開始曜日、テーマ選択、保存ボタン。
- 操作: 保存で設定更新。戻る/キャンセルで変更破棄。初回の設定完了は初期設定画面が担当。
- 認証要否: 必須。
- ナビゲーション: サイドメニューボタンで開閉し、メニューに「ダッシュボード」「設定」「ログアウト」を配置。

## エラールート / リダイレクト

- 目的: 未認証アクセスや存在しないページに対する案内。
- 主なUI: メッセージと導線。未認証ならホームまたは認証画面へ、存在しないページならホームへ戻す CTA。
- 認証要否: ケースにより。
