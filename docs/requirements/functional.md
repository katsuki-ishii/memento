# 機能要件 (Functional Requirements)

- 認証: Cognito を用いたサインアップ/ログイン/ログアウト、セッション更新（PKCE）。
- ユーザー設定: ユーザー名・生年・寿命・週開始曜日などを保存し、ライフグリッド表示に反映。
- ライフグリッド: ユーザー設定の寿命年数×52週のグリッドを描画し、現在週をハイライト。過去/未来を色分けして時間の有限性を可視化。
- イベント (Events): 週に紐づく出来事ログを CRUD。メモ/感情スコアを任意で付与。
- データ管理: 個人データを DynamoDB に保存し、認証ユーザー毎に分離。クライアント側は token 以外を localStorage に極力保持しない。

- 週番号の算出: 日本時間(JST)で、週開始は月曜。誕生日からの経過日数/7の整数値を週IDとする。
