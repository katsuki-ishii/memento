# 機能要件 (Functional Requirements)

- 認証: Cognito を用いたサインアップ/ログイン/ログアウト、セッション更新（PKCE）。
- ユーザー設定: 生年・寿命・週開始曜日などを保存し、ライフグリッド表示に反映。
- ライフグリッド: ユーザー設定の寿命年数×52週のグリッドを描画し、現在週をハイライト。目標やイベントを重畳表示。
- 目標 (Goals): タイトル、カテゴリ、目標週/年、ステータス（未着手/進行/完了）で CRUD。
- イベント (Events): 週に紐づく出来事ログを CRUD。タグ/メモ/感情スコアを任意で付与。
- 進捗指標: 完了目標数、記録済み週数などのサマリーを表示。
- データ管理: 個人データを DynamoDB に保存し、認証ユーザー毎に分離。クライアント側は token 以外を localStorage に極力保持しない。
