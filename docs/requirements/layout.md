# レイアウト / テーマ要件

- 目的: ホーム/認証/ダッシュボードで一貫した UI スケルトンを提供し、ダーク/ライトの切替を容易にする。
- ベース: シェル型レイアウト (`App.vue`) でヘッダー・メイン・フッター領域を定義。グローバルナビはダッシュボードのみ表示。
- テーマ: Tailwind のカスタムトークンを `tailwind.config.js` で定義（ベースカラー、アクセント、背景/カード、警告/エラー）。`data-theme="light|dark"` 切替を body に反映。
- 対応デバイス: PC ブラウザのみ想定。レスポンシブ対応は範囲外で、サイドナビは PC レイアウトを基本に「ボタンで開閉（初期クローズ）」するドロワー表示とする。
- アクセシビリティ: コントラスト比 AA 以上、フォーカスリング維持、キーボード操作でナビ開閉可能。
- 状態表示: トースト/モーダル/ロードインジケータは UI ストア経由で制御し、グローバルコンポーネントとして配置。
- ページ固有の余白・幅はレイアウトコンポーネントのスロット props で調整（例: `maxWidth="lg"`）。
