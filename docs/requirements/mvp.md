# MVP スコープ

## 含める

- 認証: Cognito サインアップ/ログイン/ログアウト（PKCE）。
- ユーザー設定: ユーザー名・生年・寿命・週開始曜日を保存し、グリッドサイズと表示に反映。
- ライフグリッド: ユーザー設定の寿命×52週のグリッド描画、現在週ハイライト。
- イベント記録: 週単位でイベントを CRUD（タイトル/メモ/感情スコア）し、グリッドに反映。
- 進捗サマリー: 記録済み週数などの簡易指標を表示。
- 設定画面: 上記設定変更とログアウト導線。
- API: 設定/イベント用のRESTエンドポイント、JWT検証。

## 含めない（非MVP）

- 目標管理（Goal CRUD、カテゴリ、ステータス管理）。
- 高度な分析（週間レポート、グラフ可視化）。
- 共有/コラボ機能（公開リンク、招待）。
- 通知/リマインダー（メール/プッシュ）。
- データエクスポート/インポート。
- マルチ環境（本番/ステージング）自動デプロイ。

## 技術的前提

- フロント: Vue 3 + Vite + JS + Tailwind。
- バック: API Gateway(REST) → Lambda(Node 22, JS) → DynamoDB 単一テーブル。
- デプロイ: 手動（AWSコンソール想定）。CI は lint/format のみ。
