# ユーザーストーリー / 用語集

## ストーリー

- ユーザーとして、ログインして自分専用のライフグリッドを見たい。
- ユーザーとして、寿命や開始年を設定してグリッドを自分に合わせたい。
- ユーザーとして、週ごとの出来事を記録し、後から振り返りたい。

## 用語集

- ライフグリッド: 寿命設定×52週のセルで人生を可視化するビュー。
- 週ID: 誕生日起点での経過日数/7 の整数値（週開始は月曜、JST基準）。
- イベント (Event): 特定の週に紐づく出来事ログ。メモ/タグ/感情スコアを持てる。
- ユーザー設定: 生年、寿命、週開始曜日、表示テーマなどの個別設定。
