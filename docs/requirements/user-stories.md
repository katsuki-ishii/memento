# ユーザーストーリー / 用語集

## ストーリー

- ユーザーとして、ログインして自分専用のライフグリッドを見たい。
- ユーザーとして、寿命や開始年を設定してグリッドを自分に合わせたい。
- ユーザーとして、長期の目標を登録し、達成状況を週グリッド上で確認したい。
- ユーザーとして、週ごとの出来事を記録し、後から振り返りたい。
- ユーザーとして、完了済み目標数や記録済み週数などの進捗を把握したい。

## 用語集

- ライフグリッド: 81年×52週のセルで人生を可視化するビュー。
- 週ID: `year` と `week` の組で表すインデックス（ISO週を前提）。
- 目標 (Goal): 達成したい項目。カテゴリ、目標週/年、ステータスを持つ。
- イベント (Event): 特定の週に紐づく出来事ログ。メモ/タグ/感情スコアを持てる。
- ユーザー設定: 生年、寿命、週開始曜日、表示テーマなどの個別設定。
