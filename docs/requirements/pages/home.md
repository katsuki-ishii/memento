# ホーム（非認証）要件

- 目的: 初めて訪れたユーザーにコンセプトを伝え、サインアップ/ログインへ誘導する。
- UI: ロゴ + タイトル "Memento"、サブメッセージ（例: "あなたの時間を、週で見える化する"）、CTAボタン2つ「サインアップ」「ログイン」。
- 操作: CTAで認証フローへ遷移（Cognito Hosted UI/PKCE）。
- 認証: 不要（誰でもアクセス可）。認証済みの場合は初期設定またはダッシュボードへリダイレクト。
- ナビ: サイドメニューボタンは非表示。フッター等に簡易リンクのみ。
- スタイル: Notionライク白黒、広めの余白、最小限のアクセントカラー。
