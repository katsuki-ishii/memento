# 初期設定画面要件

- 目的: 初回ログイン後に必須のユーザー設定を入力・保存し、ホーム利用を可能にする。
- フィールド: username（必須）, birthYear（必須）, lifespan(年, 必須), weekStart（初期:月曜, 必須）, theme（任意）。
- 操作: 保存で API PATCH /me/settings を実行し、成功したらホームへ遷移。キャンセルはログアウトまたはホームへ戻るリンクのみ。
- フロー: 認証成功→設定未完の場合ここへリダイレクト。設定済みユーザーはスキップしてホームへ。
- 認証: 必須。
- スタイル: Notionライク白黒、フォームはシンプルに。
