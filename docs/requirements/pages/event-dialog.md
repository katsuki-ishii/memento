# イベント編集ダイアログ要件

- 目的: 週に紐づくイベントの登録/編集/削除。
- フィールド:
  - title: タイトル（最大100文字）
  - note: メモ（任意）
  - mood: 感情スコア（選択式、5段階）
    - 表示: 顔文字（😢 😞 😐 😊 😄）
    - 保存値: `'very-bad'` | `'bad'` | `'neutral'` | `'good'` | `'very-good'`
  - weekId: 表示のみ（`YYYY-WXX` の週ID、変更不可）
- 操作:
  - 保存: POST（新規）/ PATCH（更新）
  - 削除: DELETE
  - キャンセル: ダイアログを閉じる（ESCキー、オーバーレイクリック、×ボタン）
- トリガー: ダッシュボードのセルクリック。
- バリデーション:
  - title: 最大100文字
  - note: 制限なし
  - weekId: 変更不可（表示のみ）
- 認証: 必須（ダッシュボード経由のみ）。
- スタイル: モーダル、白黒基調、アクセント最小。フェードイン/スライドアップアニメーション。
