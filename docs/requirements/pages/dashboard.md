# ダッシュボード要件

- 目的: 寿命×52週グリッドで現在位置とイベントを俯瞰し、進捗指標を提示する。
- データ: ユーザー設定(寿命, weekStart, username, theme)、イベント一覧、算出された週IDと残余週数。
- UI要素:
  - グリッド: 寿命年数×52セル。現在週ハイライト、イベント有セルの色分け。
  - サマリー: 記録済み週数、残り寿命（週・日・%）。
  - フィルタ/ジャンプ: 年/週指定でスクロール・フォーカス。
  - サイドメニューボタン: 開閉でメニュー（ダッシュボード/設定/ログアウト）。
- 操作:
  - セルクリック: イベント追加/編集ダイアログを開く。
  - サイドメニュー操作で設定・ログアウトへ。
- 認証: 必須。
- スタイル: Notionライクな白黒基調、広めの余白、最小限アクセント。
