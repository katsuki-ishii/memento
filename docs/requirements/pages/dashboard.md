# ホーム要件

- 目的: 寿命×52週グリッドで現在位置を俯瞰し、使った時間と残りの時間を可視化して死を意識させる。
- 前提: 認証済みかつ初期設定完了ユーザーのみアクセス。未設定なら初期設定画面へリダイレクト。
- データ: ユーザー設定(寿命, weekStart, username, theme)、算出された週ID。
- UI要素:
  - グリッド: 寿命年数×52セル。過去（使った時間）/現在週/未来（残りの時間）を色分け。画面水平中央に配置。
  - フィルタ/ジャンプ: 年/週指定でスクロール・フォーカス。
  - サイドメニューボタン: 開閉でメニュー（ホーム/設定/ログアウト）。
- 操作:
  - セルクリック: イベント追加/編集ダイアログを開く。
  - サイドメニュー操作で設定・ログアウトへ。
- 認証: 必須。
- スタイル: Notionライクな白黒基調、広めの余白、最小限アクセント。
