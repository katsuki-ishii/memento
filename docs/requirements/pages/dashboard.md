# ダッシュボード要件

- 目的: 寿命×52週グリッドで現在位置とイベントを俯瞰する。
- 前提: 認証済みかつ初期設定完了ユーザーのみアクセス。未設定なら初期設定画面へリダイレクト。
- データ: ユーザー設定(寿命, weekStart, username, theme)、イベント有無/色分け用の週イベント情報、算出された週IDと残余週数。
- UI要素:
  - グリッド: 寿命年数×52セル。現在週ハイライト、イベント有セルの色分け。画面水平中央に配置。
  - フィルタ/ジャンプ: 年/週指定でスクロール・フォーカス。
  - サイドメニューボタン: 開閉でメニュー（ダッシュボード/設定/ログアウト）。
- 操作:
  - セルクリック: イベント追加/編集ダイアログを開く。
  - サイドメニュー操作で設定・ログアウトへ。
- 認証: 必須。
- スタイル: Notionライクな白黒基調、広めの余白、最小限アクセント。
