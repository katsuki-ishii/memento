# 設定画面要件

- 目的: ユーザー設定を編集し、グリッド表示・計算に反映する。初期設定完了も兼ねる。
- フィールド: username, birthYear, lifespan(年), weekStart(初期:月曜), theme。
- 操作: 保存で設定更新（API PATCH /me/settings）。初回は保存成功でダッシュボードへ遷移。再訪時は保存後そのまま滞在またはダッシュボードへ戻るオプション。
- ナビ: サイドメニューボタンで開閉。項目: ダッシュボード/設定/ログアウト。
- 認証: 必須。未設定ユーザーは認証後ここへリダイレクトされる。
- スタイル: Notionライク白黒。
