# testing-guidelines.md

## 方針

- 単体テストは Vitest。ファイル隣に `*.spec.js` を置く。
- 重要ロジックとフォーマッタ/パーサ、日付計算は優先的にテスト。
- カバレッジ目安: コアユーティリティ・API クライアント 80% 以上を目標。

## コンポーネントテスト

- mount は必要最小限のモックで。ARIA上のテキスト/role を検証し、内部実装に依存しない。
- 非同期は `await flushPromises()` を使い、ローディング/エラー表示を確認。

## API/契約

- API クライアントはモックレスポンスで happy/sad パスを検証。
- バリデーションエラーと認証エラー(401/403)のハンドリングをテスト。

## 実行コマンド

- `npm run test`（今後追加予定）。
- CI では lint と format を必須、テストは導入後に順次追加。
